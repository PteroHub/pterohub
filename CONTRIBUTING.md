# Contributing

PteroHub is in release-candidate testing. Please open an issue with reproduction steps, expected and actual results, and the application version. Never include `.env`, API keys, customer records, server IPs, mail passwords or payment tokens.

Changes must preserve the existing single CSS/JS asset policy, mobile navigation behavior, customer ownership checks, manual provisioning and sandbox-only payments. Do not add decorative arrow glyphs to navigation or buttons.

Run PHP syntax checks, `node --check public/assets/pterohub.js`, route and view checks on a configured Laravel installation, and test changes on a staging instance before deployment.

No license has yet been selected by the owner; obtain permission before redistributing or reusing code.
