# Security policy

PteroHub RC 1.02 is a testing release and is not approved for real customer billing. Please report security vulnerabilities privately to the repository maintainers using GitHub's private vulnerability reporting feature if enabled. Do not post credentials, proof-of-concept attacks against public servers, or customer data in public issues.

Never commit `.env`, Pterodactyl Application API keys, SMTP passwords, payment credentials, database dumps, logs or private backups. Rotate any key that is accidentally disclosed. See [docs/SECURITY.md](docs/SECURITY.md).
